# 🇩🇪 德國寵物零售市場決策情報系統 (German Pet Retail & Product Development Intelligence)
##「用數據看透德國寵物市場，用 RFM 掌握真實消費者錢包，用決策科學驅動下一代產品開發。」

🎯 為什麼這個開源專案能幫你賺到錢？
德國是全歐洲最具指標性、對寵物照顧精緻度極高的成熟市場。但面對瞬息萬變的零售現況，傳統憑感覺的選品已經死透了。本專案透過現代數據分析方法，完美解決三個商業痛點：

德國市場現況透視：透過底層交易數據解析，精準掌握德國消費者在寵物零售上的消費頻率與季節性偏好。

K-means 客戶分群 (RFM 模型)：將消費者精準切分為高價值 VIP、潛力客戶與流失邊緣人，把行銷預算花在刀口上。

產品開發決策導向 (Product Development)：不猜測客戶要什麼，直接從購物籃與歷史交易數據中，找出潛在熱銷產品組合與高毛利機會。

🛠️ 專案技術與視覺化架構
本開源專案打通了數據分析的任督二脈，具備以下黃金技術棧：

Python (Pandas / Scikit-Learn)：自動化處理原始交易資料、清洗髒資料、執行 Min-Max 正規化與 K-means 機器學習分群。

Power BI 商業智慧儀表板：一鍵匯入分群結果，打造具備互動式交叉分析的動態決策看板（包含高畫質散布圖與營收貢獻長條圖）。

商業洞察轉譯：跳脫象牙塔式的演算法，將大數據直接轉化為業務主管一眼就能看懂的銷售策略。
